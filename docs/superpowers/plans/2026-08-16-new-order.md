# 4.5 New Order Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Staff can create a reservation at the counter or by phone from a single-page form accessible from the staff dashboard.

**Architecture:** Two new controllers (`Staff::OrdersController`, `Staff::CustomersController`), new DayPresenter methods for sold-out and unscheduled product buckets, and a `new-order` Stimulus controller that handles phone lookup, dynamic product loading by date, override checkboxes, and +/− steppers. No new migrations needed for reservations — `note` and `pickup_time` columns already exist. Only change: make `users.name` nullable.

**Tech Stack:** Rails 8.1, Ruby 4.0.1 (RVM gemset `massamater`), SQLite3, Stimulus 3, RSpec + FactoryBot

- [ ] **Step 3: Create the controller**

```ruby
module Staff
  class CustomersController < Staff::BaseController
    def lookup
      user = User.find_by(phone: params[:phone])
      if user
        last_source = user.reservations.order(created_at: :desc).pick(:source)
        source_name = last_source ? Reservation.sources.key(last_source) : "phone"
        render json: { found: true, name: user.name, source: source_name }
      else
        render json: { found: false, source: "phone" }
      end
    end
  end
end
```

```ruby
module Staff
  class OrdersController < Staff::BaseController
    def new; end

    def products
      return head(:bad_request) unless params[:date].present?
      date = Date.parse(params[:date])
      presenter    = DayPresenter.new(date)
      sold_out_ids = presenter.sold_out_products.map(&:id).to_set
      @available   = presenter.available_products.reject { |p| sold_out_ids.include?(p.id) }
      @sold_out    = presenter.sold_out_products
      @unscheduled = presenter.unscheduled_products
      @presenter   = presenter
      @date        = date
      render partial: "products", locals: {
        presenter: @presenter,
        available: @available,
        sold_out: @sold_out,
        unscheduled: @unscheduled,
        date: @date
      }
    rescue ArgumentError, TypeError
      head :bad_request
    end

    end
  end
end
```

### Task 7: Stimulus new-order controller

**Context:** The `new-order` Stimulus controller wires all form interactivity: phone blur → lookup, date change → product load, section toggle, override checkbox, +/− steppers.

- [ ] **Step 1: Create the controller**

Create `app/javascript/controllers/new_order_controller.js`:

```javascript
import { Controller } from "@hotwired/stimulus"

export default class extends Controller {
  static targets = [
    "phone", "name", "nameHint", "source",
    "date", "pickupTime",
    "productsContainer", "productsSection",
    "collapsibleHead", "collapsibleBody", "overrideCb",
    "stepper", "stepperVal", "quantity",
    "submit"
  ]
  static values = { lookupUrl: String }

  // ── Phone lookup ───────────────────────────────────────────────────────────

  async lookupPhone() {
    const phone = this.phoneTarget.value.trim()
    if (!phone) return

    this.nameTarget.disabled = true
    this.nameTarget.placeholder = this.nameTarget.dataset.checkingText ||
      this.element.dataset.newOrderCheckingValue || "Checking…"
    this.#setSubmitBusy(true)

    try {
      const url = `${this.lookupUrlValue}?phone=${encodeURIComponent(phone)}`
      const resp = await fetch(url, { headers: { "Accept": "application/json",
                                                  "X-Requested-With": "XMLHttpRequest" } })
      const data = await resp.json()

      if (data.found) {
        this.nameTarget.value = data.name || ""
        this.nameTarget.disabled = true
        this.#hideNameHint()
      } else {
        this.nameTarget.value = ""
        this.nameTarget.disabled = false
        this.nameTarget.placeholder = ""
        this.#showNameHint()
      }

      if (data.source && this.hasSourceTarget) {
        this.sourceTarget.value = data.source
      }
    } catch (_err) {
      this.nameTarget.disabled = false
      this.nameTarget.placeholder = ""
    } finally {
      this.#setSubmitBusy(false)
    }
  }

  nameTyped() {
    if (this.nameTarget.value.trim().length > 0) {
      this.#hideNameHint()
    }
  }

  // ── Product loading ────────────────────────────────────────────────────────

  async loadProducts() {
    const date = this.dateTarget.value
    if (!date) return

    this.productsContainerTarget.innerHTML = ""
    this.#setSubmitBusy(true)

    try {
      const url = `/staff/orders/products?date=${encodeURIComponent(date)}`
      const resp = await fetch(url, { headers: { "X-Requested-With": "XMLHttpRequest" } })
      if (resp.ok) {
        this.productsContainerTarget.innerHTML = await resp.text()
      }
    } catch (_err) {
      // silently ignore
    } finally {
      this.#setSubmitBusy(false)
    }
  }

  // ── Collapsible sections ───────────────────────────────────────────────────

  toggleSection(event) {
    const head = event.currentTarget
    const idx  = this.collapsibleHeadTargets.indexOf(head)
    const body = this.collapsibleBodyTargets[idx]
    const toggle = head.querySelector(".collapsible-toggle")
    if (!body) return

    const isHidden = body.classList.contains("hidden")
    body.classList.toggle("hidden", !isHidden)
    if (toggle) {
      toggle.textContent = isHidden
        ? (this.element.dataset.newOrderHideValue || "Hide")
        : (this.element.dataset.newOrderShowValue || "Show")
    }
  }

  // ── Override checkbox ──────────────────────────────────────────────────────

  toggleOverride(event) {
    const cb   = event.currentTarget
    const body = cb.closest(".collapsible-body")
    if (!body) return

    const enabled = cb.checked
    body.querySelectorAll(".stepper-btn, input[type=hidden]").forEach(el => {
      el.disabled = !enabled
    })
  }

  // ── Steppers ───────────────────────────────────────────────────────────────

  increment(event) {
    const id = event.currentTarget.dataset.productId
    this.#adjustQty(id, 1)
  }

  decrement(event) {
    const id = event.currentTarget.dataset.productId
    this.#adjustQty(id, -1)
  }

  #adjustQty(productId, delta) {
    const valEl   = this.stepperValTargets.find(el => el.dataset.productId === productId)
    const hiddenEl = this.quantityTargets.find(el => el.dataset.productId === productId)
    if (!valEl || !hiddenEl) return

    const current = parseInt(valEl.textContent, 10) || 0
    const next    = Math.max(0, current + delta)
    valEl.textContent  = next
    hiddenEl.value     = next
  }

  // ── Helpers ────────────────────────────────────────────────────────────────

  #showNameHint() {
    if (this.hasNameHintTarget) this.nameHintTarget.classList.remove("hidden")
  }

  #hideNameHint() {
    if (this.hasNameHintTarget) this.nameHintTarget.classList.add("hidden")
  }

  #setSubmitBusy(busy) {
    if (this.hasSubmitTarget) this.submitTarget.disabled = busy
  }
}
```
